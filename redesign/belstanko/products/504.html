Назначение

Предназначен для заточки твердосплавных буровых коронок, используемых при бурении шпуров машинами ударного действия, алмазным шлифовальным кругом с электроэрозионной правкой. Применяется на предприятиях горнодобывающей промышленности.

Особенности

Рекомендации по применяемым кругам:
- для коронок типа ККП круг алмазный специальный IEEIX-I-256 х 42 х 3х х132о х R200 х 76 ТУ2-037-524-85;
- для коронок типа КТШ круг алмазный специальный IEEIX-I-256 х 42(40) 3х х145о х R200 х76 ТУ2-037-524-85;
- для коронок типа КДП круг алмазный формы 9Н1V 250 x 42(40) x 5x x R150 x 76 ТУ88 УССР 90.1062-85
Допускается применение кругов с высотой В=40 мм.
