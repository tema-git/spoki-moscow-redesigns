Назначение

Станок С75 предназначен для продольной, поперечной и под углом распиловки досок, брусков, древесных, плитных и листовых материалов. Областью применения данного станка являются небольшие предприятия и цеха по производству столярно-строительных изделий, мебели и другие деревообрабатывающие производства.

Особенности


- Рабочий стол и каретка, отлиты из чугуна. Обеспечивают стабильную работу станка, препятствуют возникновению вибрации;
- Перемещение каретки по двум цилиндрическим направляющим исключает люфт в процессе обработки даже тяжелых и длинных заготовок. Консольная часть направляющих каретки, фиксируется винтами к специальному ребру жесткости, что обеспечивает идеальную прямолинейность движения, и как плавность ее хода;
- Подъем и опускание пилы удобно регулируется маховиком. Отображение угла наклона производится по угловой шкале;
- Для позиционирования и торцовки длинномерного материала используется направляющая линейка с миллиметровой шкалой и флажковым упором. Для торцовки под углом, направляющая линейка имеет возможность поворота;
- Для раскроя по ширине используется параллельный упор с миллиметровой шкалой, перемещение упора по массивной цилиндрической направляющей, для стабильности выставленного размера снабжен фиксирующим винтом;
- Для получения косоугольных деталей маленького формата применяется толкатель с градуированной шкалой;
- Наличие разъёма для подключения аспирации позволяет надежно удалять опилки из зоны резания.
