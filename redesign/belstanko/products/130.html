Назначение

Предназначен для выполнения разнообразных фрезерных работ по дереву (различных видов погонажных изделий, зарезки простых шипов с помощью шипорезной каретки).

Особенности

- Поставляется в трех модификациях:
- Станок с шипорезной кареткой;
- Станок с шипорезной кареткой + стальной прижим для погонажа (верхний, боковой);
- Станок с шипорезной кареткой + чугунный прижим для погонажа (верхний, боковой);
